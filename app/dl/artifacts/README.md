# DL artifacts

Trained model artifact(s) for `app.dl` (gesture recognition), produced
offline by `python -m app.dl.training.train_fixture_model`.

- `gesture_mlp_fixture.npz` — a hand-implemented NumPy `GestureMLP`
  (see `app.dl.models.network`), trained via real backpropagation
  (`app.dl.training.trainer.GestureTrainer`) on the deterministic
  synthetic fixture dataset (`app.dl.dataset.fixture`). Loaded at
  runtime by `app.dl.service.GestureRecognitionService` via
  `GestureMLP.load()`. Labeled a "fixture-trained" model everywhere it
  is surfaced -- see `docs/dl.md` for the real-dataset training path.

Do not edit this file by hand. To regenerate, see `docs/dl.md` ("How
to train").

---

Note: an earlier revision of this directory also shipped
`gesture_classifier.joblib`, a scikit-learn `Pipeline`
(`StandardScaler` + `MLPClassifier`) produced by a since-removed,
superseded training path (`app.dl.training.train`,
`app.dl.inference.inference`, `app.dl.models.landmark_schema`). That
path was never wired into `app.dl.service.GestureRecognitionService`
(which has always used the NumPy `GestureMLP` pipeline above), had
already drifted out of sync with `app.dl.dataset`'s real API (it
imported a `generate_dataset` function that did not exist), and its
matching tests failed `pytest` collection as a result. It has been
removed, along with its now-orphaned artifact and tests, so that
`app.dl` has exactly one authoritative implementation.
